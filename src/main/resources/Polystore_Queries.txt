Q_A.2.1: Flux query to obtain the values of "Arterial Blood Pressure systolic" between 01.01.2011 - 31.12.2012
-------------------------------------------------------------------------------------------------------------------------------
from(bucket: "mimic-iii")
 |> range(start:2011-01-01, stop:2012-12-31)
 |> filter(fn: (r) => r["_measurement"] == "chart_event")
 |> filter(fn: (r) => r["itemid"] == "220050")
 |> filter(fn: (r) => r["_field"] == "value" or r["_field"] == "icustay_id" or 
 |> r["_field"] == "hadm_id" or r["_tag"] == "subject_id")
 |> pivot(rowKey: ["_time"], columnKey: ["_field"], valueColumn: "_value")
-------------------------------------------------------------------------------------------------------------------------------
